# Резонанс — интерфейс оператора

Next.js 16, App Router, TypeScript, Tailwind v4. Статический экспорт: интерфейс
открывается и без сервера Node.

## Откуда берутся данные

`data/desktop.json` собирается Python и вкладывается в сборку:

```bash
cd ..
.venv/bin/python -m causa.ui.snapshot --json web/data/desktop.json
```

Внутри — рабочий стол, разборы пяти дел и исходы замечаний, вычисленные тем же
кодом, что и живой стенд. **Фронтенд не повторяет ни одного правила:** он
показывает то, что вычислил конвейер. Ни один текст вердикта, ни одна оценка
серьёзности, ни одна подпись источника здесь не собираются — они приходят
готовыми.

Отсюда и граница: интерфейс не считает новых дел. Загрузка документов потребует
живого API, а не вложенных данных.

## Команды

```bash
npm install
npm run dev     # разработка, http://localhost:3000
npm run build   # статический экспорт в out/
```

Собрать экспорт в один самодостаточный файл (чтобы показать по ссылке):

```bash
cd ..
.venv/bin/python -m causa.ui.web_bundle web/out examples/ui_web_snapshot.html
```

Сборщик проверяет, что в файле не осталось внешних ссылок, и падает, если
осталась хоть одна: файл, который где-то не откроется, выпускать нельзя.

## Что где

| Файл | Что делает |
|---|---|
| `app/page.tsx` | стол, список дел, вкладки |
| `components/VerdictHero.tsx` | главный ответ по делу и плитки состояния |
| `components/ReasoningLine.tsx` | шаги разбора, раскрывающиеся по одному |
| `components/GapQueue.tsx` | пробелы как задачи: цена ответа и способ закрыть |
| `components/Qualification.tsx` | кластер, статьи и «почему так» |
| `components/Remarks.tsx` | замечание в дело против сигнала системе |
| `components/DebateView.tsx` | спор с трёх сторон и три регистра изложения |
| `components/CaseMap.tsx` | что доходит до итога, что нет и почему |

Русская спецификация интерфейса: [`../docs/ui-spec.md`](../docs/ui-spec.md).
