# Три значения факта и бремя доказывания

## Дефект, который здесь закрывается

У факта в системе не было значения «неизвестно». Восемьдесят пять наборов
фактов, тысяча триста шестьдесят пять булевых полей, ни одного трёхзначного.

Значит «основание освобождения не установлено» кодировалось тем же битом, что
«основания освобождения нет», и подавалось в правило

```
late_performance_issue == duty_exists AND due_date_missed AND NOT valid_exception_applies
```

как факт **в пользу истца**. Система не могла отличить «я проверил, и этого
нет» от «я не знаю». Тексты слоя перевода формулировали это аккуратно
(«предпосылки не подтверждены»), но формальная модель различия не знала.

## Почему одного третьего значения было бы мало

Трёхзначный факт сам по себе задачу не решает, а перекладывает: «неизвестно» на
входе даёт «зависит» на выходе, и система начала бы отвечать «зависит» по делам,
которые суд решает уверенно.

В праве «не доказано» — не факт о мире, а **правило распределения**: у кого
бремя, тот и проигрывает по этому элементу. Поэтому третье значение введено
вместе с бременем, а не после него.

## Как это работает

Известные факты закрепляются равенством, неизвестные остаются свободными
переменными, и по каждому выводу решателю задаются два вопроса — возможно ли
«да» и возможно ли «нет»:

| ответ решателя | статус вывода |
|---|---|
| возможно только «да» | `PROVEN` — доказан при любом доопределении |
| возможно только «нет» | `REFUTED` — опровергнут при любом |
| возможно и то и другое | `DEPENDS` — зависит от неизвестного |

Для `DEPENDS` включается бремя: каждый неизвестный факт принимает значение,
невыгодное той стороне, которая обязана была его доказать.

## Одна и та же неопределённость разрешается в разные стороны

Это и есть проверка того, что бремя действительно работает. Демонстрационное
дело о поставке:

```
не знаем про основание освобождения (ст. 401 п. 2 — доказывает должник)
   Вопрос о нарушении: зависит -> принято «да»
   Недоказанное толкуется против ответчика.

не знаем про существование обязанности (доказывает кредитор)
   Вопрос о нарушении: зависит -> принято «нет»
   Недоказанное толкуется против истца.
```

Одинаковая по форме неопределённость даёт противоположный результат — потому
что бремя лежит на разных сторонах.

## Таблица бремени

Тринадцать строк, у каждой основание. Общее правило — каждая сторона доказывает
обстоятельства, на которые ссылается (статья 65 АПК РФ, статья 56 ГПК РФ);
изъятия названы прямо.

| факт | доказывает | недоказанное значит |
|---|---|---|
| существование обязанности | истец | нет |
| пропуск срока | истец | нет |
| основание освобождения | ответчик | нет (п. 2 ст. 401) |
| исполнение произведено | ответчик | нет (ст. 408) |
| ненадлежащее исполнение | истец | нет |
| денежное обязательство | истец | нет |
| срок платежа наступил | истец | нет |
| **платёж не произведён** | **ответчик** | **да** (ст. 408) |
| возражение против платежа | ответчик | нет |
| убытки заявлены | истец | нет (ст. 393) |
| причинная связь | истец | нет |
| способ защиты заявлен | истец | нет |
| истечение давности | ответчик | нет (п. 2 ст. 199) |

Строка про платёж — единственная, где недоказанность даёт «да». Причина
содержательная: доказательство исполнения лежит на должнике, и недоказанная
оплата означает, что платёж не произведён.

## Называются только решающие факты

Неизвестных может быть много, а зависеть вывод может от одного. Если объявить
неустановленными и основание освобождения, и возражение против платежа, вывод о
нарушении зависит только от первого — второе в его правило не входит вовсе.
Называть оба значило бы требовать доказывания того, что ничего не изменит.

## Правило берётся из объявленного текста

Формула для решателя собирается из `constraint_set.expressions` — из
объявленного правила, а не из второй рукописной копии на Python. Так можно с тех
пор, как сверка доказала совпадение объявленного и исполняемого во всех
88 институтах: правило впервые стало данными, и это первый его потребитель.

## Границы

**Модель одна.** Обязательство, тринадцать фактов. Остальные восемьдесят четыре
института не тронуты намеренно: сначала устройство доказывается на модели, чьи
выводы читают линия вывода, вердикт, очередь пробелов и проект документа, и
только потом переносится вширь. Обратный порядок означал бы переписать тысячу
триста полей, не проверив замысел.

**Неизвестность объявляет человек.** Система не выводит её из отсутствия
документа: отсутствие документа в деле и неустановленность факта — разные вещи,
и вторую утверждает юрист.

**Перебор ограничен.** Решающие факты ищутся перебором доопределений; при числе
неизвестных больше двенадцати честнее сказать «зависит от всех», чем считать
час. Предел записан в коде.
