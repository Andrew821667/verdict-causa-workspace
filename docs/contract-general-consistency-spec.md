# Сверка фактов между институтами: формальная модель Этапа 0

## Зачем этот слой

Один и тот же факт дела описывается предикатами нескольких институтов.
Недееспособность стороны — это `incapacity_declared_by_court` в модели лиц и
`incapacitated_person_transaction` в модели недействительности. Отсутствие
необходимого согласия — `statutory_consent_not_obtained` в модели сделок и
`required_consent_absent` в модели недействительности.

До появления этого слоя такие пары не сверялись. Рецензент мог утвердить факт в
одном институте и отрицать в другом, а анализ молча выбирал одну из версий.

Измерение до исправления: из десяти построенных межинституциональных
противоречий **все десять принимались без единого сигнала**. Конкретный вред на
примере недееспособности:

```
persons.party_lacks_capacity            True
invalidity.contractual_effect_displaced False
layer.contract_legally_effective        False   ← выбрана первая версия

юристу выдавалось: «Договор не порождает правовых последствий…
                    Сторона признана судом недееспособной, поэтому сделка ничтожна…»
```

Уверенный вывод о ничтожности при том, что модель недействительности в том же
артефакте утверждала обратное.

## Устройство

Это второй узел пакета без собственного проверенного контракта данных — после
[слоя общих положений](contract-general-effects-spec.md). Различие между ними
существенно:

| | входы | что делает |
|---|---|---|
| `general_effects` | **выводы** институтов | выводит правовые последствия |
| `general_consistency` | **факты** институтов | называет расхождения в описаниях |

Единственное исключение среди входов — `contract_concluded_prerequisites`: вывод
модели заключения договора, поскольку заключённость выводится из нескольких
фактов сразу.

## Чего слой намеренно не делает

**Не выбирает версию.** Обнаружив расхождение, слой называет его и поднимает
`requires_human_resolution`. Какая из версий верна — вопрос к рецензенту, а не к
решателю: обе стороны противоречия внесены человеком, и у формальной модели нет
основания предпочесть одну.

**Не отклоняет анализ.** Противоречие — дефект данных, но объявлять его
непреодолимым значило бы решать за юриста, что дело нельзя рассматривать.

## Гипотезы, отброшенные при проверке

Две пары предикатов выглядели противоречащими, но при проверке ими не оказались,
и в слой не вошли:

- **ст. 183 против ст. 174.** Сделка неуполномоченного лица не является
  недействительной: она считается заключённой от имени совершившего её лица.
  Утверждение `unauthorized_act_without_ratification` при
  `authority_restriction_violated = False` противоречием не является.
- **давность по ст. 196 против ст. 181.** Общий срок исковой давности — три
  года, срок по оспоримым сделкам — один год. Истечение первого ничего не
  говорит о втором.

Ещё одна пара была снята уже после реализации: `formation.acceptance_received` и
`temporal_effect.acceptance_received_by_offeror` описывают разные факты —
получение ответа-акцепта и наступление момента заключения. В демонстрационном
деле договор заключён конклюдентными действиями, и проверка на равенство давала
ложное срабатывание на каждом деле.

## Таксономия перестала быть мёртвой

`contradiction_taxonomy.py` объявлял 45 типов противоречий и не проверял ни
одного: список не импортировался никуда, кроме перечня файлов пакета. Набор
`CROSS_INSTITUTE_CONTRADICTION_TYPES` устроен иначе — тест
`test_every_declared_cross_institute_type_is_checked` требует точного совпадения
объявленных имён с полями оценки слоя, поэтому объявить тип и не проверять его
теперь нельзя.

Оставшиеся 45 имён `CONTRACT_CONTRADICTION_TYPES` по-прежнему только словарь для
разметки противоречий внутри одного института; это отражено в документации
модуля.

## Ограничения

- слой сверяет описания между собой, а не с материалами дела: согласованность не
  означает правильности;
- проверяются десять пар, а не все возможные пересечения между 90 институтами;
  расширение набора — работа, ограниченная только тем, что каждая пара должна
  быть юридически обоснована, а не выглядеть похожей;
- три из десяти измеренных противоречий отклоняются прежними проверками входов
  `reviewed_analysis` — иногда по причине, не совпадающей с самим расхождением;
- формальный результат не является судебным выводом или юридической
  консультацией.
