# Задание: выгрузка структуры Гражданского кодекса

## Запрет, который важнее задания

**Агент не должен использовать для работы ключ API какой-либо LLM — ни свой, ни
системный, ни из окружения, ни из `.env`, ни из связки ключей. Работать только
на ресурсах подписки. Нельзя брать ключи или конфигурацию из этого проекта и из
соседних проектов на машине. Нельзя запускать ничего, что тарифицируется как
платный API. Если задачу без такого ключа выполнить нельзя — остановись и
напиши человеку.**

## Зачем это нужно

Пакет объявляет, какие статьи ГК РФ разбирает каждый институт, — диапазонами
номеров. До сих пор пробелы находились только по судебной практике: если суды на
статью не ссылались, её отсутствие в модели никто не замечал.

Обход самого кодекса это измерение переворачивает: он не зависит от того, какие
дела мы отобрали. Первый черновой обход по номерам уже нашёл три статьи, которые
практика не подсвечивала ни разу, — 306, 427 и 444.

Но черновой обход знает только номера, которые назвал человек по памяти. Он не
видит статей с точкой, которых никто не назвал: между 449 и 450 может лежать
449.1, и её отсутствие не заметно. Нужен полный список статей из первоисточника.

## Что выгрузить

Структуру частей **первой и второй** ГК РФ — только структуру, не тексты норм.

Каждая строка — одна статья:

```json
{
  "number": "287.5",
  "title_ru": "Общее имущество собственников помещений, машино-мест в здании или сооружении",
  "part": 1,
  "section_ru": "Раздел II. Право собственности и другие вещные права",
  "chapter_number": "17.1",
  "chapter_title_ru": "Право собственности и другие вещные права на здания, сооружения, объекты незавершенного строительства, помещения и машино-места",
  "paragraph_ru": "",
  "in_force": true,
  "source_ref": "consultant:GK1:287.5"
}
```

Поля:

| поле | что в нём |
|---|---|
| `number` | номер статьи строкой: `"7"`, `"16.1"`, `"123.28"` |
| `title_ru` | название статьи дословно |
| `part` | `1` или `2` |
| `section_ru` | раздел, к которому статья относится |
| `chapter_number` | номер главы строкой: `"9"`, `"9.1"`, `"17.1"` |
| `chapter_title_ru` | название главы дословно |
| `paragraph_ru` | параграф внутри главы, если он есть; иначе пустая строка |
| `in_force` | `false`, если статья утратила силу |
| `source_ref` | устойчивая ссылка на запись в базе |

**Утратившие силу статьи включать обязательно** с `in_force: false`. Иначе в
нумерации появится дыра, и обход примет её за непокрытое место.

Файл: `data/code/gk_articles.jsonl`, UTF-8, по одному объекту JSON на строку.

## Опись

Рядом — `data/code/inventory.md`, и в ней ответы на четыре вопроса:

1. **Откуда взято.** Какая база, какая редакция, на какую дату.
2. **Сколько статей** в каждой части, сколько из них утратили силу, сколько с
   точкой в номере.
3. **Как проверено.** Главы обязаны покрывать часть без разрывов и без
   наложений: последняя статья главы и первая статья следующей должны идти
   подряд. Напиши, чем ты это проверил и сошлось ли.
4. **Чего в выгрузке нет.** Например: части третья и четвёртая не выгружались —
   пакет их не моделирует.

## Чего делать не нужно

- **Не выгружай тексты статей.** Нужны номера, названия и структура. Тексты — это
  объём, который здесь не нужен, и лицензионный вопрос, который не нужен тем более.
- **Не выгружай подзаконные акты и федеральные законы.** Отдельная задача, и
  критерий отбора для неё ещё не выработан.
- **Не придумывай статьи, которых не нашёл.** Пропуск, названный пропуском,
  полезнее выдуманной полноты. Если раздел не открылся — так и напиши в описи.

## Как сдать

Ветка `data/code-structure-export`, коммит с двумя файлами, push в
`verdict-causa-workspace`. Ветку основывай **на текущем `main`**: прошлая
выгрузка практики пришла на ветке от старого состояния, и слияние целиком
удалило бы всё, что сделано после него.

## Как проверить себя до сдачи

```bash
python - <<'PY'
import json, collections
rows = [json.loads(l) for l in open("data/code/gk_articles.jsonl", encoding="utf-8") if l.strip()]
print("статей:", len(rows))
print("по частям:", collections.Counter(r["part"] for r in rows))
print("утратили силу:", sum(not r["in_force"] for r in rows))
print("с точкой в номере:", sum("." in r["number"] for r in rows))
print("уникальных номеров:", len({(r["part"], r["number"]) for r in rows}))
chapters = collections.OrderedDict()
for r in rows:
    chapters.setdefault((r["part"], r["chapter_number"]), []).append(r["number"])
print("глав:", len(chapters))
PY
```

Сойтись должно так: уникальных номеров столько же, сколько строк; частей две;
глав в части первой около тридцати, в части второй около тридцати одной.
