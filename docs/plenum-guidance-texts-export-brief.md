# Задание: попунктный чистый экспорт постановлений Пленума

## Запрет, который важнее задания

**Не использовать для работы ключ API какой-либо LLM.** Работать только на
ресурсах подписки. Задача решается экспортом из локальной подписки
КонсультантПлюс тем же способом, каким выгружен 127-ФЗ, — детерминированно,
без модели. Если без API-ключа LLM задачу выполнить нельзя — остановись и
напиши человеку.

## Почему это отдельное задание, а не повтор прошлого

Пять постановлений Пленума уже лежат в `data/guidance/` — но выгружены
другим способом: это сырой дамп HTML-страницы КонсультантПлюс в Markdown,
с всплывающими подсказками похожих дел, вставленными прямо внутри текста
постановления (`<div>...</div>`, ссылки на карточки дел с тултипами в
несколько килобайт каждая). Для чтения человеком через веб-интерфейс это
нормально — подсказки скрыты по умолчанию. Как текст источника права для
модели — нет: попытка механически вычистить разметку кодом нашла место, где
65 пунктов постановления № 25/2015 (с 15-го по 79-й) пропали при удалении
одной такой подсказки, и обрывки текста тех же подсказок остаются вплетены
в текст даже там, где нумерация пунктов не пострадала.

127-ФЗ выгружен **другим** способом — постатейно, из карточки закона,
без этого мусора. Нужен тот же способ, применённый к постановлениям Пленума:
не дамп HTML-страницы, а чистый постатейный (точнее — попунктный) экспорт.

## Что выгрузить

### Часть 1: пять документов, которые уже определены

Тем же способом, каким выгружен 127-ФЗ — попунктно, из карточки документа в
КонсультантПлюс, без разметки страницы и без всплывающих подсказок:

| документ | зачем |
|---|---|
| Постановление Пленума ВС РФ от 23.06.2015 № 25 | пункты 63-68 — доставка сообщения (статья 165.1); плюс пункты о недействительности сделок (раздел постановления с этой темой — сам определи по оглавлению документа) |
| Постановление Пленума ВС РФ от 21.12.2017 № 54 | целиком — перемена лиц в обязательстве |
| Постановление Пленума ВС РФ от 24.12.2020 № 45 | целиком — поручительство |
| Постановление Пленума ВС РФ от 27.06.2023 № 23 | целиком — залог вещей |
| Постановление Пленума ВС РФ от 11.06.2020 № 6 | целиком — прекращение обязательств |

Файл: `data/guidance/plenum_paragraphs.jsonl`, UTF-8, по объекту JSON на
строку — одна строка на пункт постановления:

```json
{
  "document_slug": "plenum-vs-45-2020",
  "paragraph": "1",
  "text_ru": "1. В соответствии со статьей 361 Гражданского кодекса Российской Федерации...",
  "section_ru": "Общие положения",
  "source_ref": "consultant:LAW:372286:1"
}
```

| поле | что в нём |
|---|---|
| `document_slug` | тот же слаг, что уже в `data/guidance/index.jsonl` |
| `paragraph` | номер пункта строкой, как в документе (`"1"`, `"14"`) |
| `text_ru` | текст пункта дословно, без ссылок и разметки страницы |
| `section_ru` | заголовок раздела документа, если пункт под ним стоит; иначе пустая строка |
| `source_ref` | устойчивая ссылка вида `consultant:LAW:<номер карточки>:<пункт>` |

Четыре монотематичных постановления (№ 54/2017, № 45/2020, № 23/2023, №
6/2020) выгружаются целиком — каждое посвящено ровно одному вопросу, так что
частичная выгрузка не нужна. У № 25/2015 разделов много (постановление о
разделе I части первой ГК в целом), поэтому по нему выгружаются два
раздела: пункты 63-68 (доставка сообщения) и раздел о недействительности
сделок целиком — найди его по оглавлению документа, там это явно выделенный
раздел с собственным заголовком.

## Опись

`data/plenum-paragraphs-inventory.md`. Ответы на четыре вопроса:

1. **Как выгружено** — через какую карточку/раздел КонсультантПлюс, чем
   отличается от прошлого сырого MD-дампа этих же пяти документов (тот
   дамп не трогать и не удалять — он остаётся историческим источником).
2. **Сколько пунктов** выгружено по каждому документу.
3. **Как проверено, что пункты не потерялись** — сверка нумерации 1..N без
   разрывов, как делалось для статей ГК и 127-ФЗ.
4. **Что не нашлось** из пяти документов части 2 — прямо и честно.

## Как сдать

Ветка `data/plenum-paragraphs-export`, основанная на текущем `main`. Коммит,
push в `verdict-causa-workspace`. Пул-реквест не открывай.

## Как проверить себя до сдачи

```bash
python - <<'PY'
import json
from collections import defaultdict

rows = [json.loads(l) for l in open("data/guidance/plenum_paragraphs.jsonl", encoding="utf-8") if l.strip()]
print("строк всего:", len(rows))

by_doc = defaultdict(list)
for r in rows:
    by_doc[r["document_slug"]].append(r)

for slug, items in sorted(by_doc.items()):
    empty = sum(1 for r in items if not r["text_ru"].strip())
    noise = sum(1 for r in items if "<div" in r["text_ru"] or "](" in r["text_ru"] or "http" in r["text_ru"])
    print(f"{slug}: {len(items)} пунктов, пустых {empty}, с остатками разметки {noise}")
PY
```

«С остатками разметки» должно выйти нулём для каждого документа — это и
есть проверка того, что тултипы и HTML не просочились в текст.
