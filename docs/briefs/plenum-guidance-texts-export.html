Попунктный чистый экспорт постановлений Пленума

Пять постановлений уже лежат в data/guidance/ как сырой дамп HTML-страницы — с тултипами похожих дел прямо внутри текста. Механическая очистка кодом потеряла 65 пунктов одного документа. Нужен тот же чистый способ, каким выгружен 127-ФЗ, применённый к постановлениям Пленума.

Запрет, который важнее задания

Не использовать для работы ключ API какой-либо LLM. Работать только на ресурсах подписки. Задача решается экспортом из локальной подписки тем же способом, каким выгружен 127-ФЗ, — детерминированно, без модели. Если без API-ключа LLM задачу выполнить нельзя — остановись и напиши человеку.

1

Почему это отдельное задание, а не повтор прошлого

Пять постановлений Пленума уже лежат в data/guidance/ — но выгружены другим способом: это сырой дамп HTML-страницы КонсультантПлюс в Markdown, с всплывающими подсказками похожих дел, вставленными прямо внутри текста постановления (<div>, ссылки на карточки дел с тултипами в несколько килобайт каждая). Для чтения человеком через веб-интерфейс это нормально — подсказки скрыты по умолчанию. Как текст источника права для модели — нет.

Попытка механически вычистить разметку кодом нашла место, где 65 пунктов постановления № 25/2015 (с 15-го по 79-й) пропали при удалении одной такой подсказки, и обрывки текста тех же подсказок остаются вплетены в текст даже там, где нумерация пунктов не пострадала.

127-ФЗ выгружен другим способом — постатейно, из карточки закона, без этого мусора. Нужен тот же способ, применённый к постановлениям Пленума: не дамп HTML-страницы, а чистый попунктный экспорт.

Опись и как сдать

data/plenum-paragraphs-inventory.md — как выгружено и чем отличается от прошлого дампа (тот дамп не трогать), сколько пунктов по каждому документу, как проверена нумерация без разрывов, что не нашлось.

Ветка data/plenum-paragraphs-export, основанная на текущем main. Коммит, push в verdict-causa-workspace. Пул-реквест не открывай. 

python - <<'PY'
import json
from collections import defaultdict

rows = [json.loads(l) for l in open("data/guidance/plenum_paragraphs.jsonl", encoding="utf-8") if l.strip()]
by_doc = defaultdict(list)
for r in rows:
    by_doc[r["document_slug"]].append(r)

for slug, items in sorted(by_doc.items()):
    empty = sum(1 for r in items if not r["text_ru"].strip())
    noise = sum(1 for r in items if "<div" in r["text_ru"] or "](" in r["text_ru"] or "http" in r["text_ru"])
    print(f"{slug}: {len(items)} пунктов, пустых {empty}, с остатками разметки {noise}")
PY

«С остатками разметки» должно выйти нулём для каждого документа.
