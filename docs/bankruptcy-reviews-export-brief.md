# Задание: пять обзоров практики по банкротству

## Запрет, который важнее задания

**Не использовать для работы ключ API какой-либо LLM.** Работать только на
ресурсах подписки. Задача решается поиском и экспортом из уже сохранённого
локального корпуса — того же, что использовался для выгрузки практики и
Пленумов. Если без API-ключа LLM задачу выполнить нельзя — остановись и
напиши человеку.

## Контекст

При выполнении задания на 127-ФЗ (`docs/law127fz-export-brief.md`) в общем
локальном корпусе `consultant-data/court-practice/*/converted-md/*.md` были
обнаружены, но сознательно не перенесены пять документов — их происхождение
из панели связанных документов карточки 127-ФЗ подтвердить не удалось, и это
было верным решением по буквальному смыслу того задания.

Сейчас это отдельный, осознанный запрос именно на эти пять документов —
самих по себе, без привязки к панели связи какой-либо карточки.

## Что выгрузить

Пять документов из общего корпуса судебной практики:

1. Обзор судебной практики по банкротству за **2022 год**;
2. Обзор судебной практики по банкротству за **2023 год**;
3. Обзор судебной практики по банкротству за **2024 год**;
4. Обзор судебной практики **по требованиям залогодержателей** в банкротстве;
5. Обзор судебной практики **по участию арбитражного управляющего** в
   банкротстве.

Найди их точные заголовки, номера и даты утверждения Президиумом ВС РФ —
как они названы в самом корпусе, а не по моему пересказу тем выше. Если
какой-то из пяти в корпусе на самом деле не один документ, а несколько
(например, обзор за год мог выходить отдельно по разным темам) — перенеси
все найденные, а не только один, и опиши это в описи.

Каталог: `data/guidance/` — тот же, что использовался раньше, не создавай
параллельный. Имя файла — устойчивый слаг по образцу уже лежащих
(`plenum-vs-25-2015.md` → по аналогии `obzor-bankruptcy-2023.md` и так
далее — предложи слаги сам, по смыслу документа). Текст переносится дословно,
как лежит в корпусе, без переоформления.

Пополни существующий `data/guidance/index.jsonl` **новыми** строками — не
переписывай уже лежащие пять записей. Формат строки такой же, как у них:

```json
{
  "slug": "obzor-bankruptcy-2023",
  "title_ru": "точный заголовок документа, как в корпусе",
  "kind": "обзор_практики",
  "adopted": "YYYY-MM-DD",
  "source_path": "/Users/legalai/consultant-data/court-practice/.../converted-md/....md",
  "paragraphs": 0
}
```

`paragraphs` — реальное число абзацев в перенесённом файле, не заглушка.

## Опись

Добавь в конец `data/norm-texts-inventory.md` новый раздел «Пять обзоров по
банкротству, довыгрузка» с ответами:

1. Сколько документов на самом деле перенесено и почему (если не пять, а
   больше или меньше — по какой причине).
2. Точные заголовки и даты каждого.
3. Что из пяти в корпусе не нашлось, если что-то не нашлось — прямо так и
   написать, не подменяя и не восстанавливая по памяти.

## Как сдать

Ветка `data/bankruptcy-reviews-export`, основанная на текущем `main`. Коммит,
push в `verdict-causa-workspace`. Пул-реквест не открывай.
